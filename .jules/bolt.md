## 2024-11-20 - Avoid functional array chaining and spread operators on large datasets in Vanilla JS
**Learning:** Using chained array methods (`.filter().map().reduce()`) or spread operators on large arrays like the `DataManager.history` (e.g. >100,000 items) is extremely problematic. The spread operator like `Math.max(...times)` crashes with "Maximum call stack size exceeded" errors. Additionally, chaining `.filter()` and `.map()` allocates intermediate arrays that significantly degrade CPU time and increase garbage collection overhead.
**Action:** When performing aggregations, finding minimums/maximums, or bucket distributions on core unpaginated datasets like `history` or `sessionData`, always replace chained functional array methods and spread operators with standard, single-pass `for` loops.
