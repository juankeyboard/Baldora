## 2024-04-30 - Prevent Stack Overflow and Minimize Array Allocation in Vanilla JS
**Learning:** Using `Math.max(...times)` with the spread operator causes a "Maximum call stack size exceeded" error in V8 (Chrome/Node.js) when the array length exceeds ~120,000 items. Additionally, chaining array methods like `.map().reduce()` or calling `.filter()` multiple times allocates intermediate arrays, adding significant GC pressure and execution time for large datasets (e.g. gameplay history).
**Action:** When calculating statistics or finding min/max values on large datasets in vanilla JS, replace the spread operator and chained array methods with a single-pass `for` loop. This avoids the call stack limitation and speeds up processing significantly (up to 4-5x faster depending on array size).
