## 2024-05-19 - Avoid Spread Operator on large arrays for Math.max/min
**Learning:** Using `Math.max(...array)` or `Math.min(...array)` on large datasets (like `history` arrays > 100,000 items) will throw a "Maximum call stack size exceeded" error. The original code in `getResponseTimeDistribution` was throwing this when the history was large.
**Action:** Instead of spreading arrays to find max/min, use a simple `for` loop to find extremes, which is both safe from call stack limits and significantly faster (avoids large array parameter passing). Also, when bucketing histogram data or calculating stats, single-pass `for` loops avoid intermediate array allocations (from `.map()` or `.filter()`) and string building inside the loop, resulting in a ~8x-10x performance speedup.
