## 2024-06-25 - Avoid array method chaining and spread operator on large arrays in Baldora
**Learning:** In the vanilla JS architecture of Baldora, processing large `history` data arrays (e.g., in `DataManager`) with chained array methods like `.filter().map().reduce()` causes significant CPU overhead. Additionally, using the spread operator (`...`) with functions like `Math.max` or `Math.min` on these large arrays (e.g., >100,000 items) leads to 'Maximum call stack size exceeded' errors.
**Action:** When performing data aggregations or processing on large arrays, replace chained methods with single-pass `for` loops to minimize memory allocations and CPU overhead. Avoid using the spread operator for array arguments; use loops or `reduce` (without spread) for operations like finding minimums or maximums.
