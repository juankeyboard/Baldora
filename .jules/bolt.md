## 2024-05-22 - [Avoid spread operator and chained array methods for large datasets]
**Learning:** Using the spread operator with `Math.max(...array)` on large arrays (e.g. >100,000 items) causes 'Maximum call stack size exceeded' errors in this architecture. Single-pass for loops avoid this entirely and perform significantly faster for histogram bucket generation. Additionally, intermediate array allocations via chained `map`, `filter`, and `reduce` in functions like `getSessionStats` cause memory bloat and CPU overhead, which can be avoided with single-pass accumulation loops.
**Action:** When handling arrays that may grow significantly (such as game history), prefer single-pass `for` loops for finding max/min or calculating aggregates. Avoid `...` spread over unbounded collections, and avoid chained `.filter().map().reduce()` since they allocate new arrays at each step.
