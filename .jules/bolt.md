## 2024-06-07 - Avoid spread operator and string interpolation in large array processing
**Learning:** Using the spread operator (`...`) with `Math.max` or `Math.min` on large data arrays (e.g. > 100k items) causes 'Maximum call stack size exceeded' errors. Furthermore, using string interpolation and string-based property lookups (`bins[label] = ...`) inside a large loop introduces significant CPU overhead and array allocations, making bucketing operations extremely slow (~4400ms for 100k items).
**Action:** Use a single-pass `for` loop to find maximums/minimums, and use integer-indexed arrays (`new Array(numBins).fill(0)`) for counting/bucketing. Map indices to string labels only once after the counting loop finishes. This reduces execution time to ~130ms (34x faster) and prevents stack overflow crashes.
