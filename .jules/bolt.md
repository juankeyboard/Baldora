## 2024-06-25 - Avoid array spread operator for finding mathematical extrema over large arrays
**Learning:** Using `Math.max(...times)` or `Math.min(...times)` over very large data sets (e.g. `DataManager.history` which can grow rapidly) will trigger "Maximum call stack size exceeded" errors in JavaScript due to limits on the number of arguments a function can accept. Additionally, allocating intermediate map arrays (`const times = this.history.map(...)`) and looking up object dictionaries using template literals in loops creates significant CPU overhead for huge datasets.
**Action:** When tracking statistics over large internal analytics data, implement a single-pass `for` loop to identify min/max values manually. Additionally, prefer using integer indexing (buckets) during iterative aggregation, transforming indexes into string keys only at the end. This drastically avoids both crashes and processing bottlenecks.
