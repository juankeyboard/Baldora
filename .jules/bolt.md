## 2026-05-20 - [Data Processing Arrays Optimization]
**Learning:** Using `Math.max(...array)` on large arrays like the `history` and `sessionData` in vanilla Javascript environments causes a `Maximum call stack size exceeded` error. In addition, iterating and performing bucketing using string-keyed properties in a histogram (like `bins[\`\${i / 1000}-\${(i + binSize) / 1000}s\`] = 0;`) causes substantial overhead in JS engines when running over hundreds of thousands of items.
**Action:** When filtering, mapping, or finding extremes over large data sources, always use single-pass integer-indexed `for` loops. Prevent using the spread operator on large arrays, and instead track extremes via comparison inside loops. For histogram bucket building, bucket items by integers (`binCounts[binIndex]++`) and only label map the outputs after the loop concludes.
