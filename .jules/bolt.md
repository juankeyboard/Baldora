## 2024-05-24 - Maximum call stack size exceeded in array spread and Array Method Chaining Overhead
**Learning:** Using the spread operator with `Math.max(...array)` or `Math.min(...array)` throws a "Maximum call stack size exceeded" error when the array has more than ~100,000 elements. Additionally, in vanilla JS, chaining array methods (`filter().map().reduce()`) on large datasets (e.g. game history) creates a significant CPU overhead because it iterates over the array multiple times and creates intermediate arrays.
**Action:** Avoid the spread operator for max/min on potentially large datasets; instead, iterate through the array manually to find the min/max values. Replace chained array methods with a single-pass `for` loop that performs filtering and aggregation simultaneously.
