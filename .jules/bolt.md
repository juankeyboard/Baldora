## 2026-04-14 - Avoiding Stack Overflows and Allocation Overhead in Large Arrays
**Learning:** Using `Math.max(...array)` on very large arrays (e.g., historical user data) causes 'Maximum call stack size exceeded' errors because the spread operator passes all elements as arguments to the function. Additionally, chaining array methods like `.filter().map().reduce()` on large datasets causes significant performance overhead in this vanilla JS architecture by iterating over the array multiple times and allocating intermediate arrays.
**Action:** When calculating statistics or metrics on potentially unbounded arrays like `history` or `sessionData`, always prefer single-pass `for` loops. To find the maximum value, iterate through the array rather than using `Math.max` with spread syntax.
