## 2024-06-25 - Avoid Math.max/min with Spread Operator on Large Data Arrays
**Learning:** Using `Math.max(...array)` or `Math.min(...array)` throws a "Maximum call stack size exceeded" error when the array size exceeds roughly 120,000 items. This happens because the spread operator expands the array into individual arguments, hitting the JavaScript engine's maximum argument limit for function calls. This application uses `DataManager.history` and `DataManager.sessionData` which can easily reach this scale over long sessions or imported datasets.
**Action:** When finding extremes in large datasets (especially `history` or `sessionData`), always use a single-pass `for` loop (e.g., `let max = 0; for(let i=0; i<arr.length; i++) if(arr[i] > max) max = arr[i];`) instead of `Math.max(...arr)`.
