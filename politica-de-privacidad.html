Política de Privacidad

Última actualización: 9 de marzo de 2026

Volver al Inicio
Este documento define la política de privacidad de Baldora.org, adaptada a una aplicación web educativa para practicar multiplicación, con autenticación opcional. El contenido toma como referencia la legislación colombiana vigente.

1. Datos que Baldora.org Recopila

Dato Fuente Propósito Almacenamiento
Nickname Usuario no autenticado Identificar la sesión local Sesión local / CSV exportado
Nombre de Google Google Sign-In Identidad del usuario autenticado Firebase
Email Google Sign-In Asociación de cuenta y acceso Firebase
Foto de perfil Google Sign-In Mostrar avatar en interfaz URL externa / Firebase
Historial de partidas Uso de la app Seguimiento de progreso y perfil Firebase Realtime Database
Estadísticas agregadas Uso de la app Analíticas personales y comunidad Firebase Realtime Database

Datos que Baldora.org No Recopila

  • Datos de tarjetas de crédito o débito directamente en servidores propios.
  • Datos biométricos o ubicación geográfica precisa.
  • Datos sensibles no necesarios para la función educativa del producto.

2. Uso de los Datos

Los datos se usan exclusivamente para:

  1. Permitir el uso de Baldora.org como herramienta educativa interactiva.
  2. Guardar el historial de partidas y el progreso del usuario autenticado.
  3. Mostrar analíticas y métricas personales.
  4. Permitir la exportación de sesiones en formato CSV.
  5. Mejorar la experiencia y estabilidad del producto.

3. Compartición con Terceros

Tercero Datos compartidos Propósito
Google / Firebase Datos de autenticación, perfil y persistencia Login, hosting y base de datos.
Baldora.org no vende datos personales a terceros.

4. Derechos del Usuario (Ley 1581 de 2012)

El usuario puede solicitar el acceso, rectificación, supresión o portabilidad de sus datos. Para ello, debe contactar a través del canal de soporte oficial.

5. Transferencias Internacionales

La infraestructura opera en servidores de Google/Firebase fuera de Colombia. Al usar las funciones de autenticación, el usuario acepta esta transferencia.
